App Android **offline-first** para acompañar la deshabituación tabáquica: métricas en tiempo real, soporte ante *cravings*, minijuegos, recuperación biológica, logros y recaídas sin castigo.

**Requisitos:** Android 8.0+ (API 26) · Sin cuenta · Sin servidor · Datos en el dispositivo

```bash
git clone https://github.com/entreunosyceros/dejalo.git
cd dejalo
./gradlew :app:assembleDebug
```
